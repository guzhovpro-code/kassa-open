# Касса

Личная касса в Telegram: пишете трату или поступление обычной фразой («кофе 150 лир», «получил 100 долларов на карту»)
или наговариваете голосом, бот присылает карточку, запись подтверждается в мини-приложении. Там же форма, отчёты за
день, месяц и любой период, динамика по месяцам, обмен валют и пересчёт в доллары по курсу.

У каждого свой бот и своя база: код ставится на ваш компьютер или сервер, данные не уходят никуда, кроме вашего
Telegram. Лицензия MIT.

## Что понадобится

Минимум, без которого Касса не заработает:

1. **Docker** с плагином compose (`docker compose version`) на сервере или компьютере, который включён всегда.
2. **Telegram-бот**: напишите @BotFather, команда `/newbot`, сохраните токен.
3. **Ваш числовой Telegram id**: напишите @userinfobot.
4. **Публичный адрес HTTPS** для мини-приложения.

Всё остальное необязательно: голос (Groq), вечернее напоминание, свой домен, часовой пояс.

### Зачем нужен адрес HTTPS

Мини-приложение (форма и отчёты) открывает Telegram, причём со своих серверов, а не с вашего телефона. Поэтому форма
должна быть доступна из интернета по HTTPS. Сам бот (приём сообщений, карточки) работает через long polling и
**домена не требует**: он сам ходит к Telegram. Но без адреса кнопка «Касса» не откроется: текстом и голосом можно
писать, записывать и подтверждать нельзя (запись денег идёт только из мини-приложения).

Три пути, выберите один (подробности и команды - в разделе «HTTPS для мини-приложения»):

| Путь | Что нужно | Минусы | Для кого |
|---|---|---|---|
| А. Свой домен и Caddy | свой домен (платный), DNS на ваш сервер, открытые порты 80 и 443 | нужен домен и сервер с публичным IP | постоянная работа |
| Б. Временный туннель `cloudflared` (quick tunnel) | программа `cloudflared`; аккаунт Cloudflare не нужен | адрес меняется при каждом перезапуске туннеля, после смены нужно править `.env`; туннель надо держать запущенным | проба на пару дней |
| В. `tailscale funnel` | уже установленный Tailscale с включённым Funnel | нужен аккаунт Tailscale, Funnel включается в его настройках | у кого Tailscale уже есть |

Для постоянной работы нужен домен или постоянный туннель. Временный адрес подходит, чтобы попробовать: после
перезапуска он станет другим, и кнопка «Касса» перестанет открываться, пока вы не обновите `KASSA_PUBLIC_URL`.
Cloudflare в пути Б - только бесплатный туннель, регистрироваться там не нужно.

## Установка за 10 минут

```bash
git clone <адрес этого репозитория> kassa && cd kassa
cp .env.example .env && chmod 600 .env
```

Заполните в `.env`:

| Переменная | Что вписать |
|---|---|
| `KASSA_BOT_TOKEN` | токен от @BotFather |
| `KASSA_ALLOWED_IDS` | ваш Telegram id (несколько - через запятую); остальным бот не отвечает |
| `KASSA_PUBLIC_URL` | адрес HTTPS без слэша в конце, например `https://kassa.example.org` |
| `KASSA_INTERNAL_TOKEN` | любая случайная строка от 32 знаков: `openssl rand -hex 20` |
| `KASSA_PATH_TOKEN` | необязательно: случайный префикс адреса (от 32 знаков), тогда страница живёт по `<адрес>/<префикс>/` |
| `KASSA_TZ` | необязательно: часовой пояс «дня», например `Europe/Berlin` (по умолчанию UTC) |
| `KASSA_REMINDER_ENABLED`, `KASSA_REMINDER_TIME` | необязательно: `1` включает вечернее напоминание, если за день нет записей; время `ЧЧ:ММ` (21:30) |
| `KASSA_VOICE_PROVIDER` | необязательно: `local` (по умолчанию, расшифровка на этой машине), `groq` (облако Groq) или `off` (без голоса) |
| `KASSA_WHISPER_MODEL` | для `local`: `small` (по умолчанию, около 1 ГБ памяти), `base`, `tiny`; на слабой машине берите `tiny` или `off` |
| `KASSA_GROQ_API_KEY`, `KASSA_GROQ_MODEL` | для `groq`: ключ с console.groq.com (бесплатный тариф), модель по умолчанию `whisper-large-v3-turbo` |
| `INSTALL_WHISPER` | необязательно: `0` собирает образ без faster-whisper (для `groq` и `off`: образ легче, `local` тогда не работает) |
| `KASSA_UID`, `KASSA_GID` | необязательно: `id -u` и `id -g` пользователя, который владеет папкой `data` |

Запуск:

```bash
mkdir -p data
echo "KASSA_UID=$(id -u)" >> .env && echo "KASSA_GID=$(id -g)" >> .env
docker compose up -d --build
docker compose ps          # api должен стать healthy, bot - running
curl -fsS http://127.0.0.1:8080/healthz      # с KASSA_PATH_TOKEN: .../<префикс>/healthz
```

Откройте своего бота в Telegram, нажмите `/start`: придёт кнопка «Касса», она же появится слева от поля ввода.

## HTTPS для мини-приложения

Порт 8080 слушает только `127.0.0.1`. Выведите его наружу одним из трёх способов (таблица выбора - в начале файла)
и впишите итоговый адрес в `KASSA_PUBLIC_URL`, затем `docker compose up -d`.

**А. Свой домен и обратный прокси.** Домен направлен на ваш сервер, прокси сам получает сертификат. Пример для Caddy:

```
kassa.example.org {
    reverse_proxy 127.0.0.1:8080
}
```

**Б и В. Бесплатный туннель, домен не нужен.**

- `cloudflared tunnel --url http://127.0.0.1:8080` (cloudflared quick tunnel): печатает адрес вида
  `https://что-то.trycloudflare.com`. Адрес меняется при каждом перезапуске туннеля, после смены правьте
  `KASSA_PUBLIC_URL` и делайте `docker compose up -d`.
- `tailscale funnel 8080`: постоянный адрес вашего устройства в Tailscale, нужен включённый Funnel.

Рекомендуем задать `KASSA_PATH_TOKEN`: тогда страница не открывается по угадываемому адресу (запись всё равно
защищена подписью Telegram и списком id).

## Как записывать

- **Текстом**: напишите боту «кофе 150 лир», «такси 12 евро картой», «получил 200 долларов», «поменял 100 евро на
  лиры». Бот пришлёт карточку: кнопки «Верно» (у части карточек «Записать») и «Исправить» открывают форму с заполненными полями, запись
  появляется после «Записать» в форме; «Отмена» или «Это не деньги» закрывает черновик, ничего не записав. Сумму, которую бот не понял, он не
  угадывает: ответит, что ничего не записано.
- **Голосом**: отправьте боту голосовое сообщение, оно расшифровывается и дальше идёт как текст. Способ выбирает
  `KASSA_VOICE_PROVIDER`:
  - `local` (по умолчанию): на вашей машине, `faster-whisper`, внешних сервисов нет. Первое голосовое скачивает
    модель (около 0,5 ГБ для `small`) и отвечает дольше обычного; модель лежит в `data/whisper`. На слабой машине
    возьмите `KASSA_WHISPER_MODEL=tiny` или выберите `groq` или `off`.
  - `groq`: расшифровка в облаке Groq, нужен ваш бесплатный ключ с console.groq.com в `KASSA_GROQ_API_KEY`.
    **Звук голосового уходит в Groq** (на сервер сторонней компании) на расшифровку; текст и база остаются у вас.
    Работает без модели на машине: образ можно собрать с `INSTALL_WHISPER=0`.
  - `off`: голос выключен, на голосовое бот отвечает, что принимает только текст.
  Старая настройка `KASSA_VOICE_ENABLED=0` без `KASSA_VOICE_PROVIDER` по-прежнему означает `off`.
- **В форме мини-приложения**: поля заполняются с клавиатуры телефона, а кнопка с микрофоном на клавиатуре
  диктует голосом прямо в поле; отдельного кода для этого не нужно.
- «Только карта» и «Не тратил» отмечают день без записей (удобно с вечерним напоминанием).
- **Отчёты**: вкладки «Сегодня», «Месяц» и «Период». В «Периоде» выберите две даты (включительно; одна и та же дата
  в обоих полях - один день) или нажмите «7 дней» или «30 дней»; не длиннее 400 дней. Вид тот же, что у «Месяца»:
  итоги по валютам, «≈ USD», расходы по категориям, поступления по способам.

## Резервная копия, обновление, откат, удаление

```bash
python3 scripts/backup_db.py            # data/kassa.db -> backups/kassa-<время>.db (права 600)
git pull && docker compose up -d --build     # обновление; схема базы обновляется сама
```

- **Восстановление из копии**: `docker compose down`, положить снимок как `data/kassa.db`, удалить рядом
  `kassa.db-wal` и `kassa.db-shm`, `docker compose up -d`.
- **Откат версии**: `docker compose down`, `git checkout <прежний коммит>`, восстановить базу из копии (база новее
  кода не откроется), `docker compose up -d --build`. Перед обновлением делайте копию.
- **Удаление**: `docker compose down --rmi local`, затем удалить папку проекта (вместе с `data/`, если данные не нужны).
  Бота можно удалить у @BotFather командой `/deletebot`.

## Безопасность

- Бот отвечает только id из `KASSA_ALLOWED_IDS`; остальные сообщения игнорируются.
- Запись, правка и удаление денег идут только из мини-приложения с подписью Telegram (Ed25519 по id бота) и
  проверкой id. Токен бота и внутренний порт 8081 денег записать не могут.
- Контейнеры без root-прав, с read-only файловой системой, без лишних возможностей; 8081 не опубликован.
- `.env` и `data/` не попадают в git (`.gitignore`). Токен бота не показывайте и не публикуйте; если токен утёк,
  выпустите новый у @BotFather (`/revoke`) и обновите `.env`.
