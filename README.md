# Касса

Личная касса в Telegram: пишете трату или поступление обычной фразой («кофе 150 лир», «получил 100 долларов на карту»)
или наговариваете голосом, бот присылает карточку, запись подтверждается в мини-приложении. Там же форма, отчёты за
день и месяц, динамика по месяцам, обмен валют и пересчёт в доллары по курсу.

У каждого свой бот и своя база: код ставится на ваш компьютер или сервер, данные не уходят никуда, кроме вашего
Telegram. Лицензия MIT.

## Что понадобится

- Docker с плагином compose (`docker compose version`) на сервере или домашнем компьютере, который включён всегда.
- Бот: напишите @BotFather, команда `/newbot`, сохраните токен.
- Ваш числовой Telegram id: напишите @userinfobot.
- Адрес HTTPS для мини-приложения (Telegram открывает только HTTPS): свой домен или бесплатный туннель, см. ниже.

## Установка за 10 минут

```bash
git clone <адрес этого репозитория> kassa && cd kassa
cp .env.example .env && chmod 600 .env
```

Заполните в `.env`:

| Переменная | Что вписать |
|---|---|
| `KASSA_BOT_TOKEN` | токен от @BotFather |
| `KASSA_ALLOWED_IDS` | ваш Telegram id (несколько - через запятую); остальным бот не отвечает |
| `KASSA_PUBLIC_URL` | адрес HTTPS без слэша в конце, например `https://kassa.example.org` |
| `KASSA_INTERNAL_TOKEN` | любая случайная строка от 32 знаков: `openssl rand -hex 20` |
| `KASSA_PATH_TOKEN` | необязательно: случайный префикс адреса (от 32 знаков), тогда страница живёт по `<адрес>/<префикс>/` |
| `KASSA_TZ` | необязательно: часовой пояс «дня», например `Europe/Berlin` (по умолчанию UTC) |
| `KASSA_REMINDER_ENABLED`, `KASSA_REMINDER_TIME` | необязательно: `1` включает вечернее напоминание, если за день нет записей; время `ЧЧ:ММ` (21:30) |
| `KASSA_VOICE_ENABLED`, `KASSA_WHISPER_MODEL` | необязательно: голос включён (1), модель `small`; `0` выключает голос, `tiny` и `base` легче |
| `KASSA_UID`, `KASSA_GID` | необязательно: `id -u` и `id -g` пользователя, который владеет папкой `data` |

Запуск:

```bash
mkdir -p data
echo "KASSA_UID=$(id -u)" >> .env && echo "KASSA_GID=$(id -g)" >> .env
docker compose up -d --build
docker compose ps          # api должен стать healthy, bot - running
curl -fsS http://127.0.0.1:8080/healthz      # с KASSA_PATH_TOKEN: .../<префикс>/healthz
```

Откройте своего бота в Telegram, нажмите `/start`: придёт кнопка «Касса», она же появится слева от поля ввода.

## HTTPS для мини-приложения

Порт 8080 слушает только `127.0.0.1`. Выведите его наружу одним из двух способов и впишите итоговый адрес в
`KASSA_PUBLIC_URL`, затем `docker compose up -d`.

**А. Свой домен и обратный прокси.** Домен направлен на ваш сервер, прокси сам получает сертификат. Пример для Caddy:

```
kassa.example.org {
    reverse_proxy 127.0.0.1:8080
}
```

**Б. Бесплатный туннель, домен не нужен.**

- `cloudflared tunnel --url http://127.0.0.1:8080` (cloudflared quick tunnel): печатает адрес вида
  `https://что-то.trycloudflare.com`. Адрес меняется при каждом перезапуске туннеля, после смены правьте
  `KASSA_PUBLIC_URL` и делайте `docker compose up -d`.
- `tailscale funnel 8080`: постоянный адрес вашего устройства в Tailscale, нужен включённый Funnel.

Рекомендуем задать `KASSA_PATH_TOKEN`: тогда страница не открывается по угадываемому адресу (запись всё равно
защищена подписью Telegram и списком id).

## Как записывать

- **Текстом**: напишите боту «кофе 150 лир», «такси 12 евро картой», «получил 200 долларов», «поменял 100 евро на
  лиры». Бот пришлёт карточку: кнопки «Верно» и «Исправить» открывают форму с заполненными полями, запись появляется
  после «Записать» в форме; «Отмена» закрывает черновик, ничего не записав. Сумму, которую бот не понял, он не
  угадывает: ответит, что ничего не записано.
- **Голосом**: отправьте боту голосовое сообщение, оно расшифровывается на вашем сервере (`faster-whisper`, внешних
  сервисов нет) и дальше идёт как текст. Первое голосовое скачивает модель (около 0,5 ГБ для `small`) и отвечает
  дольше обычного; модель лежит в `data/whisper`. Выключить голос: `KASSA_VOICE_ENABLED=0`.
- **В форме мини-приложения**: поля заполняются с клавиатуры телефона, а кнопка с микрофоном на клавиатуре
  диктует голосом прямо в поле; отдельного кода для этого не нужно.
- «Только карта» и «Не тратил» отмечают день без записей (удобно с вечерним напоминанием).

## Резервная копия, обновление, откат, удаление

```bash
python3 scripts/backup_db.py            # data/kassa.db -> backups/kassa-<время>.db (права 600)
git pull && docker compose up -d --build     # обновление; схема базы обновляется сама
```

- **Восстановление из копии**: `docker compose down`, положить снимок как `data/kassa.db`, удалить рядом
  `kassa.db-wal` и `kassa.db-shm`, `docker compose up -d`.
- **Откат версии**: `docker compose down`, `git checkout <прежний коммит>`, восстановить базу из копии (база новее
  кода не откроется), `docker compose up -d --build`. Перед обновлением делайте копию.
- **Удаление**: `docker compose down --rmi local`, затем удалить папку проекта (вместе с `data/`, если данные не нужны).
  Бота можно удалить у @BotFather командой `/deletebot`.

## Безопасность

- Бот отвечает только id из `KASSA_ALLOWED_IDS`; остальные сообщения игнорируются.
- Запись, правка и удаление денег идут только из мини-приложения с подписью Telegram (Ed25519 по id бота) и
  проверкой id. Токен бота и внутренний порт 8081 денег записать не могут.
- Контейнеры без root-прав, с read-only файловой системой, без лишних возможностей; 8081 не опубликован.
- `.env` и `data/` не попадают в git (`.gitignore`). Токен бота не показывайте и не публикуйте; если токен утёк,
  выпустите новый у @BotFather (`/revoke`) и обновите `.env`.
